# ctoe — AI Language Coach

> 把**想说的话**变成地道的外语；把**遇到的外语**变成自己的笔记。
> 常驻桌面的小工具：`Ctrl+Shift+Space` 呼出，说完就走。
>
> Windows 10/11 · 数据只存本机 · 无账号 · 无服务器 · **自备 API Key**

*A desktop language coach for Windows. Write in your native language → get natural phrasing in the one you're learning; paste something you read → get its meaning plus the phrases worth remembering. The browser extension is just a second entrance to the same pipeline.*

```
你想说的话 ──▶ Generate ──▶ 地道的外语 ──┐
                                        ├──▶ Learn ──▶ My Learning（句子 + 学习点）
网页上遇到的话 ──────────────────────────┘
```

## 它是什么

它不做「逐字翻译」，只做两件事：

| 你做什么 | 它给你什么 |
| --- | --- |
| 用**母语**写下想说的话 | 那门**正在学的语言**里，母语者真的会写出来的说法（保留原意、语气、情绪，不中式、不加戏） |
| 把在别处读到的**外语**粘进来 | 这段话的**母语意思**，以及里面值得学的东西 |
| 对结果点一次 `Learn` | 这句话里值得记的表达 / 句式 / 词汇 / 语法，**连整句话一起**存进本机 `My Learning` |

方向由「**你的语言档案 + 你点的标签页**」决定，不让你每次选，也不猜你打的是什么语言。

**它不是什么**：不是翻译器（不逐词对应）、不是浏览器插件（不读网页 DOM）、没有账号 / 云同步 / 排行榜 / 间隔重复、不自动粘贴、不发帖、不监听键盘、不读别的窗口。

## 下载与安装

从 **Releases** 下载 `ctoe-setup-<版本>-x64.exe`（安装版）或 `ctoe-portable-<版本>-x64.exe`（免安装，双击即用）。

> 体积说明：安装包约 **89 MB**，安装后约 **317 MB**。其中绝大部分是 Electron 运行时（Chromium + Node），我们自己的代码不到 1 MB；已经裁掉了用不到的 GPU / 媒体组件和 55 种语言包中的 49 种。

| | 安装版 | 免安装版 |
| --- | --- | --- |
| 装到哪 | 当前用户目录（安装时可改） | 不安装，解压即用 |
| 开机自启 | 支持 | 不可靠（每次解压到临时目录，启动项会指向一个已不存在的路径） |
| 浏览器扩展「门铃」（`ctoe://` 唤起） | 支持 | 可能失效（临时目录每次不同） |
| 卸载 | 设置 → 应用 → 卸载 | 直接删 exe |

**第一次安装会看到 Windows 的蓝色警告**（「Windows 已保护你的电脑」）：本项目没有购买代码签名证书。点 **更多信息 → 仍要运行** 即可。

**系统要求**：Windows 10 / 11（x64）。macOS / Linux 理论可用，但没有实测。

### 装完之后你会看到什么

**屏幕上只会出现一个圆形的小球**（56×56，半透明、置顶、不占任务栏）。它不会弹出一个大窗口，这是有意的：

- 点它 → 展开成面板；
- 按 `Ctrl+Shift+Space` → 同样展开（在任何程序里都能按）；
- 小球可以用鼠标拖到屏幕任意位置，位置会记住；
- 如果屏幕上找不到它，看**系统托盘**（Windows 默认会把新图标折叠进「^」里）；
- 托盘菜单：打开面板 / 隐藏悬浮球 / 设置 / 退出。

> 展开后**还不能直接用**——先去配一个 API Key。见下一节。

## 5 分钟上手

```
① 配 AI（约 2 分钟）  →  ② 说第一句话  →  ③ 点 Learn  →  ④（可选）装浏览器扩展
```

**① 配 AI**：设置 → AI 服务 → 填 API Key（详见下一节）。

**② 说第一句话**：`Ctrl+Shift+Space` 展开 → 在输入框用母语写一句 → `Generate`（或 `Alt+Enter`）→ 结果逐字出现 → `Copy`（或 `Alt+Q`）粘到任何地方。

**③ 学一句**：对结果点 `Learn` → 下方出现学习点，并已自动存进 `My Learning`（面板右上角可进）。**没有 Save 按钮**：点 Learn 就等于保存。

**④（可选）浏览器**：把网页上选中的句子也送进来 —— 见[浏览器扩展](#浏览器扩展可选)。

第一次打开时面板顶部会有一张**三步卡**（配 AI / 学第一句话 / 让浏览器也能学），读的全是真实状态，走完自己消失。

## 配置 AI（第一次必看）

### 为什么软件不带 Key

这个程序**不提供 AI 服务、也没有任何服务器**。所有翻译和学习都由**你自己的** AI 账户完成，费用直接付给服务商，不经过本项目的任何地方。

所以装上之后必须先填三样东西，否则点 `Generate` 只会得到「还没有配置 API Key」。

### 三样东西分别是什么

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| **API Key** | 服务商发给你的密钥 | `sk-xxxxxxxxxxxxxxxx` |
| **Base URL** | 服务商的接口地址，**填到 `/v1` 为止**（不用自己加 `/chat/completions`） | `https://api.deepseek.com/v1` |
| **Model** | 模型名（服务商文档里的 model id） | `deepseek-chat` |

任何 **OpenAI 兼容**（`POST /chat/completions`）的服务都能用，不限于下面这几家。

### 支持哪些服务商

| 服务商 | 拿 Key 的地方 | Base URL | 常用 Model | 备注 |
| --- | --- | --- | --- | --- |
| **DeepSeek**（默认） | <https://platform.deepseek.com/api_keys> | `https://api.deepseek.com/v1` | `deepseek-chat` | 便宜、快，中文场景够用，国内直连 |
| OpenAI | <https://platform.openai.com/api-keys> | `https://api.openai.com/v1` | `gpt-4o-mini` | 需要绑卡，部分地区需代理 |
| OpenRouter | <https://openrouter.ai/keys> | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` | 一个 Key 用很多家的模型 |
| 硅基流动 | <https://cloud.siliconflow.cn/account/ak> | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` | 国内直连，有免费额度 |
| 智谱 GLM | <https://open.bigmodel.cn/usercenter/apikeys> | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | 国内直连 |
| Moonshot / Kimi | <https://platform.moonshot.cn/console/api-keys> | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | 国内直连 |
| **Ollama**（本地） | 不需要 | `http://localhost:11434/v1` | `llama3.1` / `qwen2.5` | 完全离线，见下文 |
| **LM Studio**（本地） | 不需要 | `http://localhost:1234/v1` | 加载的模型 id | 完全离线 |

> Model 名以各家控制台为准，写错会报「模型不存在」。

### 手把手

1. 打开浏览器，按上表到服务商控制台**注册并创建 API Key**（通常要先充值/绑定支付方式），复制那串以 `sk-` 开头的字符。
2. 点托盘图标（或小球）展开面板 → 右上角 **设置**。
3. 第一组就是 **AI 服务**：
   - 把 Key 粘进 **API Key**；
   - 展开下面的 **高级**，填 **Base URL** 和 **Model**（默认已经是 DeepSeek 的值，用 DeepSeek 就只需填 Key）。
4. 滚到页面底部点 **保存**（开关类改完就生效；Key / URL / Model 这几个输入框要点保存）。保存后立刻生效，不需要重启。
5. 回面板写一句话 → 点 `Generate`。**出结果了就说明配好了。**

### 配好了怎么验证

- 最快：打一句「我觉得这个说法有点太绝对了」→ `Generate`，几秒内应该开始逐字出现。
- 第一次会慢一点（要发请求、等第一个字）。
- 出错时面板给的是人话，不是 HTTP 码。对照下一张表。

### 用本地模型（不花钱、不联网）

装了 [Ollama](https://ollama.com/) 或 LM Studio 的话，AI 可以完全跑在本机：

```bash
ollama pull qwen2.5          # 或者 llama3.1
ollama serve                 # 默认监听 11434
```

设置里填：

| 字段 | 值 |
| --- | --- |
| Base URL | `http://localhost:11434/v1` |
| Model | `qwen2.5`（必须是 `ollama list` 里有的名字） |
| API Key | **随便填一个非空字符串**，例如 `local` |

最后一条容易踩坑：本程序要求 Key 非空才发请求（为了避免误发未鉴权的请求到公网服务），本地服务通常会忽略这个头，所以填个占位符即可。

### 公司网络 / 代理

程序的请求走 Node 的 `fetch`，**不会自动读取 Windows 的系统代理**。所以：

- 优先选国内可直连的服务商（DeepSeek / 硅基流动 / 智谱 / Moonshot）；
- 必须走代理时，用系统的「全局代理 / TUN 模式」让流量透明转发，或者在本机搭一个反向代理、把 Base URL 指到它（例如 `http://127.0.0.1:8080/v1`）。

### 报错了对照这张表

| 面板提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 还没有配置 API Key | 没填 Key | 见上面的步骤 |
| **API Key 无效**，请检查设置 | Key 错 / 过期 / 被删 / 无权限（401、403） | 重新复制一次，注意别带空格 |
| **模型不存在**，请在设置里检查模型名称 | Model 写错，或账号没有该模型权限（400、404） | 对照服务商文档改成准确的 model id |
| **请求过于频繁或额度不足** | 429，或账户余额为 0 | 充值 / 等一会儿 / 换模型 |
| **连接 AI 服务失败**，请检查网络 | 网络不通，或 Base URL 写错 | 检查 URL 是否填到 `/v1`、有没有多余的 `/chat/completions` |
| **AI 服务响应超时** | 60 秒没响应 | 换更快的模型 / 检查网络 |
| **AI 返回的内容无法识别** | 模型太弱，没按要求输出 | 换一个更强的模型 |

### 费用大概多少

- **本程序免费**，不抽成；费用只发生在你自己的服务商账户。
- 按 token 计费：一次普通生成（几十个字）通常在**几厘钱**量级，DeepSeek 这类更便宜；具体看服务商价目。
- 点 `Learn` 会多发一次请求（讲解），`Understand` 只要一次。
- 想完全不花钱：用 Ollama / LM Studio 本地模型。
- 想先看看界面长什么样：设置里把 Provider 切成 `Mock`（本地假数据、不联网、不花钱），界面右上角会出现「Mock 模式」角标。

### Key 安全吗

- Key 只存在**这台电脑**的配置文件里，用系统安全存储（Windows DPAPI）加密；不进界面、不进日志、不进仓库。
- 本程序没有服务器，Key 不会被上传到任何地方；它只会发给你填的那个服务商。
- 换电脑要重新填；想清空就点「清除已保存的 Key」。

## 日常使用

面板长这样（同一对语言的两种方向）：

```
悬浮球 ──点击 / Ctrl+Shift+Space──▶ 面板
                                    ├─ 顶部：My Learning · 最近翻译 · 设置 · − · ×
                                    ├─ 档案：Native: 中文 · Learning: English
                                    ├─ 标签：[ Say it ]  [ Understand ]     ← 全部的方向控制
                                    ├─ 输入框：用母语写下想说的话…（自动聚焦）
                                    ├─ 输出框：结果（只读，流式出现）
                                    └─ 工具条：[Natural ▼] [ Generate ]
                                               [ Copy ] [ Learn ] [ 重新生成 ]
```

### 两个模式（= 两个方向）

面板顶部一行是你的档案：`Native: 中文 · Learning: English`。右边两个标签页就是全部的方向控制：

| 标签 | 方向 | 你做什么 |
| --- | --- | --- |
| `Say it` | 母语 → 正在学 | 写下想说的话，得到一个地道的说法 |
| `Understand` | 正在学 → 母语 | 粘贴读到的话，得到母语意思 + 学习点 |

两个模式各有自己的草稿，切回来还在。改语言在设置 → 语言（支持中文 / English / Français / Español / Русский / العربية，任意两种之间都能组方向）。

### Learn：点一下就是记住

对屏幕上那句**正在学的语言**点 `Learn`，它会挑出这句话里值得记的点：

| 每个点包含 | 内容 |
| --- | --- |
| 表达 | 结果里的原片段（不翻译） |
| 意思 | 用**你的母语**解释 |
| 为什么有用 | 一句话 |
| 例句 | 用**正在学的语言**造一句 |
| 例句翻译 | 这句例句的母语翻译（不会这门外语也能核对） |

- 数量由句子决定（简单句 1 个，复杂句可能很多），不凑数、不封顶。
- 排序：有用的表达 > 句式 > 词汇 > 语法。
- **点 Learn 就是保存**：这句话连同全部学习点已经写进本机，分析块下方给一张回执 `Added to My Learning · #000001`。
- 生成结果本身不落盘：只有点 Learn 才会记。

### My Learning

面板右上角进入。按「母语 → 正在学」分类，点进去看句子；顶部搜索框跨全部语言对搜索；知识点默认折叠；每条能删（真删，编号不复用）。

### 导出与打印（Word）

My Learning 页底部有两个按钮：

| 按钮 | 做什么 |
| --- | --- |
| **导出为 Word** | 每个语言对生成一份 `.docx`（`Chinese_English.docx` / `English_Chinese.docx` —— 两个方向是**两份**文件）。每份先逐句列出原文、译文、方向、日期，以及这句话里**全部**学习点（类型 / 表达 / 意思 / 为什么有用 / 例句 / 例句翻译）；最后按表达、句式、词汇、语法整理成索引表，每行标着来源编号（`#000003`）。A4 版面、表头跨页重复，直接打印。 |
| **打开数据文件夹** | 直接打开放着 `learned.json` 的那个文件夹。 |

- 默认存到 **`文档\ctoe 学习记录`**（没有就自动创建），**每次都会弹对话框**，可以改到 U 盘或别的目录。
- 写完会自动在资源管理器里**选中生成的文件**，不用自己去找。
- 导出只读取学习记录，不改动 `learned.json`，也不联网。

### 最近翻译

设置里打开后，每次生成 / 解释的原文和结果会记在本机（最多 50 条），可以一键清空。每一行都能直接点 `Learn`——按**那一行当时**的语言方向入库，哪怕你后来换了正在学的语言。

### 朗读

每条**正在学的语言**的文字旁边有一个喇叭（学习点、例句、生成结果、读到的原句）。点才读，用的是 Windows 自带的语音，不联网、不录音。没装对应语言的语音时喇叭是灰的。

### 快捷键

| 快捷键 | 范围 | 作用 |
| --- | --- | --- |
| `Ctrl+Shift+Space` | 系统级（可在设置里改） | 悬浮球 ⇄ 面板 |
| `Alt+Enter` 或 `Ctrl+Enter` | 面板内 | 生成 / 解释 |
| `Alt+R` | 面板内 | 重新生成 |
| `Alt+Q` | 面板内 | 复制结果 |
| `Ctrl+Shift` + 划词 | 网页（装了扩展） | 弹出划词浮层 |

## 浏览器扩展（可选）

装不装都能用。装了之后，**在网页上遇到的那句话**也能一键送进同一个 `Learn`（同一套 Prompt、同一份 `My Learning`）。

### 它是什么

一个浏览器扩展 **OmniTranslate 万译**（Manifest V3），本程序给它加了一个「学习这句」的入口。扩展自己负责网页翻译，桌面端负责翻译质量与学习记录。

**扩展的源码就在本仓库的 [`extension/`](extension/) 目录里**，不是外部下载的：`extension/src` 是源码，`extension/dist` 是构建产物，安装包里的 `resources/extension` 就是从它拷进去的。所以桌面端和插件的**版本号永远相同**（`npm run sync:version` 在构建时把 `package.json` 的版本写进 `manifest.json`，`npm test` 里有一条契约测试盯着）。

### 安装（3 步，只能你手动点）

浏览器不允许别的程序替你装扩展，所以最后一步必须由你自己点：

1. 桌面端：设置 → **浏览器连接** → 打开开关 → 点 **`打开扩展文件夹`**（随安装包附带的扩展就在里面）。
2. 浏览器地址栏进 `chrome://extensions`（或 `edge://extensions`）→ 右上角打开 **开发者模式** → 点 **`加载已解压的扩展程序`** → 选中刚才打开的文件夹（**不是**里面的 `dist`）。
3. 回到桌面端点 **`复制口令`** → 点浏览器工具栏上的扩展图标 → 把口令粘进弹窗 → 点 **`连接`** → 看到「✓ 已连接（端口 43110，协议 v1）」就配好了。

### 两个入口

| 入口 | 怎么用 |
| --- | --- |
| 划词浮层 | **按住 `Ctrl+Shift`（macOS 是 `Cmd+Shift`）**选中一句话 → 浮层底部点「学习这句」 |
| 右键菜单 | 选中文字 → 右键 → **`发送到 AI Language Coach（学习这句）`** → 页面右下角出回执 |

> 浮层那条必须先按住 `Ctrl+Shift`：普通划词在网页上太常见，不加区分会到处弹窗。不想记快捷键就用右键那条。

学完桌面端会自己跳到「来自浏览器」页，显示原文、译文、学习点和朗读。

### 排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 看不到「学习这句」 | 设置里没打开开关，或页面没重新加载（装完扩展刷新一次页面） |
| 「还没有配对」 | 口令没粘；到桌面端设置里复制一次 |
| 「连接口令不正确」 | 口令被重置过（重置会让旧口令立刻失效），重新复制粘贴 |
| 「没有检测到桌面端」 | 程序没开；或者设置里的「浏览器连接」开关关着 |
| 右键菜单里没有这一项 | 重新加载一次扩展；还不行就重启浏览器 |
| 端口被别的程序占用 | 设置页会直说；重启一次程序（端口在 43110–43119 里自动挑） |

## 数据与隐私

三份文件，全部在本机（默认 `%APPDATA%\ctoe`，可用环境变量 `CTOE_DATA_DIR` 指到别处）：

| 文件 | 存什么 | 什么时候写 |
| --- | --- | --- |
| `config.json` | 设置、加密后的 API Key 与扩展口令、窗口位置 | 改设置 / 配对 / 移动窗口 |
| `learned.json` | 学过的句子 + 每句的全部学习点 | **只有点 Learn** |
| `recent.json` | 最近 50 条生成 / 解释（默认关） | 开关打开时，每次生成 / 解释 |

- **没有账号、没有服务器、没有数据库、没有埋点**；用本地模型时可以全程离线。
- 只有你点生成 / 解释 / Learn 时，对应文本才会发往**你自己配置的服务商**。
- 悬浮球只监听自己窗口的鼠标；不监听键盘、不读别的程序。剪贴板只在你点「粘贴」时读一次。
- 「读懂」必须你手动复制 + 粘贴，程序不读别的窗口、不模拟按键。
- 朗读用系统语音，不联网、不录音。
- 浏览器连接默认**关**：关着时端口根本不监听；打开后只绑 `127.0.0.1` 并要求口令。扩展送来的网页地址 / 标题只用来显示来源，**不落盘**。
- 「导出为 Word」只读取 `learned.json`，把文档写进你自己选的文件夹（默认「文档\ctoe 学习记录」）；不联网、不改动任何数据。设置页和 My Learning 页都有「打开数据文件夹」，不用记路径。
- 删数据 = 删这三个文件；卸载程序不会自动删它们。

## 常见问题

**装完没看到任何窗口？**
只有一个小球，或藏在托盘里。按 `Ctrl+Shift+Space`；托盘菜单里也有「打开面板」。

**快捷键按了没反应？**
可能被别的程序占用。托盘菜单显示当前快捷键，点它进设置换一个（例如 `Ctrl+Alt+Q`）。

**展开后打字没反应？**
输入框没焦点，点一下输入框。

**不填 Key 能用吗？**
不能得到真实结果。设置里可以把 Provider 切成 `Mock`，那只用来预览界面。

**数据能换电脑带走吗？**
把 `%APPDATA%\ctoe` 里的 `learned.json`（学习记录）和 `config.json`（设置）复制过去即可。注意 API Key 是用本机密钥加密的，**换电脑要重新填一次**。

**想把学习记录打印出来？**
My Learning 底部点「导出为 Word」：每个语言对一份 `.docx`，先逐句列出原文、译文和全部学习点，文末再按表达 / 句式 / 词汇 / 语法整理成索引，可以直接打印或再转成 PDF。

**能同时学好几门语言吗？**
可以，但一次只「正在学」一门；已经存下的记录会保留它自己的语言对。

**界面能切英文吗？**
暂时不能，界面文案目前只有中文（但语言层支持六种语言）。

**支持 Mac / Linux 吗？**
代码是跨平台的，但只在 Windows 上做过实测。

## 已知限制

- 输入上限 **8000 字符**（更长请分段）。
- 面板是固定尺寸的小窗，不支持拖拽缩放。
- 切到设置 / My Learning / 收成球会卸载面板，**没提交的草稿会清空**。
- 没有复习算法（间隔重复不在范围内）；`My Learning` 是笔记，不是成绩单。
- 朗读依赖系统语音：没装对应语言的声音时读不了。
- `Understand` 要你手动复制粘贴（原因见「数据与隐私」）。
- 扩展不能由程序代装，第一次必须自己点「加载已解压的扩展程序」。
- 右键菜单那条入口**叫不醒没在运行的桌面端**（划词那条可以）。
- 安装包没有代码签名，SmartScreen 会提示；免安装版的自定义协议唤起可能失效。
- 没有自动更新。

桌面端和插件是**一个产品的两个部分**：插件把网页上的一句话送进桌面端，桌面端负责翻译质量与学习记录。两边通过本机回环协议通信，常量在 `src/shared/types/bridge.ts` 与 `extension/src/core/bridge.mjs` 各有一份，由 `src/main/services/bridge/extensionContract.test.ts` 保证一致——端口、协议版本、文本上限，以及**两边的版本号**。

### 常用命令

```bash
npm install
npm run dev              # 开发模式
npm test                 # 桌面端 705 个测试（含扩展契约测试）
npm run test:extension   # 扩展自己的 112 个单测

```
