图片 OCR

Tesseract 完全离线：先在扩展目录运行 npm install && npm run fetch-ocr（已内置语言包：eng 英文 / chi_sim 简体中文 / chi_tra 繁體中文，另含识别核心，共约 24MB）。中文图片请选 chi_sim；中英混排可选手动组合。

连接 AI Language Coach 桌面端

配合桌面端 AI Language Coach 使用：在网页上划词后，浮层底部会出现「学习这句」，点一下就把这句话交给桌面端翻译、分析和保存；也可以右键选中的文字，直接选「发送到 AI Language Coach（学习这句）」。只有你主动点击才会发送，扩展本身不保存任何学习数据。
