# v0.1.1

第一个公开版本：**一个常驻桌面的 AI 语言教练 + 一个网页翻译插件**，两者不是两个软件，是一条管线——
插件把网页上的一句话送进来，桌面端负责翻译质量与学习记录。

## 下载

| 文件 | 适合谁 | 大小 |
| --- | --- | --- |
| `ctoe-setup-0.1.1-x64.exe` | 想装上、要开机自启、浏览器扩展能稳定唤起程序 | 约 89 MB |
| `ctoe-portable-0.1.1-x64.exe` | 解压即用，不想安装（开机自启与门铃可能不生效） | 约 89 MB |

> 安装包没有代码签名，首次运行 Windows 会提示「Windows 已保护你的电脑」→ **更多信息 → 仍要运行**。

## 这版有什么

- **两个方向**：`Say it`（母语 → 正在学的语言）与 `Understand`（正在学 → 母语）。方向由「语言档案 + 你点的标签页」决定，不猜你打的字是什么语言。
- **`Learn`**：挑出这句话里真正值得记的表达 / 句式 / 词汇 / 语法，连整句话一起存进本机的 `My Learning`，不用再按保存。
- **导出为 Word**：每个语言对一份 `.docx`（`Chinese_English.docx` / `English_Chinese.docx`），先逐句列出原文、译文和全部学习点，再按类型整理成索引，A4 版面直接打印；同时有「打开数据文件夹」，一眼看到 `learned.json` 在哪。
- **浏览器插件**（源码在本仓库 `extension/`）：网页划词「学习这句」，或右键「发送到 AI Language Coach（学习这句）」，桌面端自动跳到「来自浏览器」回执。
- **六种语言**：English / 中文 / Français / Español / Русский / العربية，任意两种之间都能组方向；朗读走系统语音。
- **自备 API Key**：DeepSeek 默认，任何 OpenAI 兼容服务（OpenAI / OpenRouter / 硅基流动 / 智谱 / Moonshot / Ollama / LM Studio）都能用；Key 用系统安全存储加密，只在本机。
- **数据全在本机**：没有账号、没有服务器、没有埋点；`config.json` / `learned.json` / `recent.json` 都在 `%APPDATA%\ctoe`。

## 第一次用

1. 双击安装 → 屏幕上**只有一个小球**，按 `Ctrl+Shift+Space` 展开（找不到就看系统托盘）。
2. 设置 → AI 服务 → 填 **API Key**（用 DeepSeek 只需填这一项）。
3. 写一句母语 → `Generate`；想学就点 `Learn`。

浏览器插件（可选，3 步）：

1. 设置 → 浏览器连接 → 打开开关 →「**打开扩展文件夹**」。
2. `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选中那个文件夹。
3. 回设置点「复制口令」→ 点扩展图标粘进去 →「连接」。

## 系统要求

- Windows 10 / 11（x64）。macOS / Linux 理论可用，未实测。
- 安装包约 89 MB、安装后约 317 MB，其中绝大部分是 Electron 运行时（本项目自己的代码不到 1 MB）。
